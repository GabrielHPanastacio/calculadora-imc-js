# Calculadora de IMC 🧮

Projeto prático desenvolvido para treinar fundamentos de desenvolvimento web (HTML5, CSS3 com Flexbox e JavaScript moderno).

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estrutura semântica dos elementos.
- **CSS3**: Estilização moderna e layout centralizado com Flexbox.
- **JavaScript**: Manipulação do DOM, tratamento de eventos, funções e condicionais para cálculo e classificação do IMC.

## 💡 Funcionalidades

- Cálculo dinâmico do Índice de Massa Corporal a partir do peso e altura.
- Validação de campos vazios ou valores inválidos.
- Classificação detalhada do IMC com base nas faixas da OMS.
- Suporte para ativação do cálculo através da tecla `Enter`.
